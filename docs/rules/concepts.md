# 概念 / Concepts

## 基本概念

### グリッド (Grid)

シミュレーション空間の基盤となる格子状の構造。

**定義:**
- 2次元の格子状の空間
- 有限または無限のサイズを持つ
- 各位置は座標 (x, y) で表される

**特性:**
- 境界条件（周期的、固定、無限など）
- グリッドのサイズと解像度
- トポロジー（矩形、六角形など）

### セル (Cell)

グリッドを構成する個々のマス目。

**定義:**
- グリッド上の最小単位
- 一意の座標を持つ
- 様々な状態や属性を保持できる

**属性:**
- 座標位置
- 地形タイプ
- 資源量
- 所有者
- アクセス可能性

### エージェント (Agent)

グリッド上で行動する主体。

**定義:**
- 自律的に意思決定を行う存在
- グリッド上を移動できる
- 他のエージェントやセルと相互作用する

**特性:**
- 位置（現在のセル）
- 所持品（資源、ツールなど）
- 状態（健康、満足度など）
- 目標と戦略
- 能力値

### 資源 (Resource)

経済活動の基盤となる物質や価値。

**定義:**
- エージェントが消費・生産・交換する対象
- セルに存在したり、エージェントが所持する

**種類:**
- 再生可能資源（食料、水など）
- 非再生可能資源（鉱物、土地など）
- 生産財（道具、建物など）
- 抽象的資源（情報、サービスなど）

**特性:**
- 量（数値）
- 品質
- 希少性
- 再生速度

### 行動 (Action)

エージェントが実行できる操作。

**基本行動:**
- 移動 (Move): 隣接セルへの移動
- 収穫 (Harvest): 資源の採取
- 生産 (Produce): 資源の変換・加工
- 交換 (Trade): 他エージェントとの取引
- 消費 (Consume): 資源の使用

**制約:**
- アクションコスト（時間、エネルギーなど）
- 前提条件（必要な資源、位置など）
- 成功確率

### 時間 (Time)

シミュレーションの進行単位。

**定義:**
- 離散的なタイムステップ
- 各ステップで全エージェントが行動

**特性:**
- ステップの長さ（現実時間との対応）
- 同期/非同期実行
- イベントのスケジューリング

## 派生概念

### 市場 (Market)

エージェント間の交換が行われる場。

**機能:**
- 価格形成
- 需要と供給のマッチング
- 取引の仲介

### 組織 (Organization)

複数のエージェントの集合体。

**例:**
- 企業
- 政府
- コミュニティ

**特性:**
- 階層構造
- 共通の目標
- 内部ルール

### インフラ (Infrastructure)

エージェントの活動を支える構造物。

**例:**
- 道路網
- 建物
- 公共施設

**効果:**
- 移動コストの削減
- 生産効率の向上
- 情報伝達の促進
