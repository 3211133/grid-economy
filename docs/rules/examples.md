# 使用例 / Examples

このドキュメントでは、grid-economyフレームワークを使った具体的なシミュレーション例を示します。

## 例1: 単純な資源採取シミュレーション

### 設定

- **グリッド**: 10×10のマス目
- **エージェント**: 5人の採取者
- **資源**: 各セルに食料が分布（ランダム）
- **目標**: 食料を集めて生存する

### ルール

1. エージェントは毎ステップ、上下左右のいずれかに移動できる
2. 現在のセルに食料がある場合、採取できる
3. 毎ステップ、エージェントは1単位の食料を消費する
4. 食料が0になったエージェントは消滅する
5. 食料は一定確率で再生する

### シミュレーションの流れ

```
ステップ1: エージェントは近くの食料を探索
ステップ2-10: 食料の多いエリアに移動しながら採取
ステップ11-: 資源の再生と消費のバランスが安定
```

## 例2: 市場経済シミュレーション

### 設定

- **グリッド**: 20×20のマス目、中央に市場
- **エージェント**: 
  - 農民（10人）: 食料を生産
  - 鉱夫（10人）: 金属を採掘
  - 商人（5人）: 取引を仲介
- **資源**: 食料、金属、貨幣

### ルール

1. 農民は農地で食料を生産
2. 鉱夫は鉱山で金属を採掘
3. 商人は市場で需要と供給をマッチング
4. 価格は需給バランスで動的に変動
5. 全員が食料を消費し、金属は道具の生産に使用

### 経済指標

- **GDP**: 総生産量の合計
- **価格指数**: 各資源の平均価格
- **所得分配**: エージェント間の富の分布
- **取引量**: 市場での取引回数

## 例3: 領土拡大シミュレーション

### 設定

- **グリッド**: 30×30のマス目
- **エージェント**: 3つの国家（各10人）
- **資源**: 土地、人口、軍事力
- **目標**: 領土を拡大し、資源を確保

### ルール

1. 各国家は特定の色でセルを占有
2. 国境で隣接する場合、軍事力の比較で領土が移動
3. 人口は食料生産量に比例して増加
4. 軍事力は人口と金属資源から生産
5. 同盟と戦争の判断はヒューリスティック

### 結果の分析

- 領土面積の時系列変化
- 軍事バランスの推移
- 同盟関係のネットワーク
- 安定均衡の形成

## 例4: 技術革新の伝播

### 設定

- **グリッド**: 25×25のマス目
- **エージェント**: 100人のイノベーター/模倣者
- **技術**: 0（旧技術）から10（最新技術）のレベル
- **目標**: 技術の普及過程を観察

### ルール

1. イノベーターは一定確率で新技術を開発
2. エージェントは近接する他者から技術を学習
3. 高い技術レベルほど生産性が向上
4. 技術の学習にはコスト（時間、資源）が必要
5. 技術レベルに応じて競争優位が変化

### 観察項目

- 技術レベルの空間分布
- 普及曲線（S字カーブ）
- イノベーターと模倣者の比率
- 技術格差の発生

## 例5: 環境と経済のバランス

### 設定

- **グリッド**: 40×40のマス目
- **エージェント**: 50人の住民
- **資源**: 森林、魚、水、汚染度
- **目標**: 持続可能な発展

### ルール

1. 森林伐採により木材を獲得（建材、燃料）
2. 漁業により魚を獲得（食料）
3. 工業により生産性向上も汚染が発生
4. 汚染は健康被害と資源再生阻害
5. 住民は短期利益と長期持続性のジレンマ

### 分析視点

- 資源の枯渇速度
- 汚染の蓄積と拡散
- 集団意思決定（規制の導入）
- 世代間の公平性

## シミュレーション設計のヒント

### パラメータ調整

- **時間スケール**: 1ステップを何秒/分/日とするか
- **空間スケール**: 1セルを何メートルとするか
- **エージェント数**: 計算コストと現実性のバランス
- **初期条件**: ランダムvs構造化配置

### バリデーション

- **定性的検証**: 期待される現象が発生するか
- **定量的検証**: 実データとの比較（可能な場合）
- **感度分析**: パラメータ変更の影響を評価
- **極限ケース**: 極端な条件での動作確認

### 可視化

- **ヒートマップ**: 資源分布、人口密度
- **時系列グラフ**: 経済指標の推移
- **ネットワーク図**: 取引関係、社会関係
- **アニメーション**: 動的な変化の表示

## まとめ

これらの例は、grid-economyフレームワークの柔軟性を示しています。
基本的な概念と法則を組み合わせることで、多様な社会経済現象をモデル化できます。
