# 法則 / Rules

## 基本法則

### 1. 空間の法則 (Spatial Rules)

#### 1.1 移動の法則

**原則:**
- エージェントは一度に1セルのみ移動可能
- 移動は隣接セルに限定される（通常は上下左右、オプションで斜め）
- 移動にはコスト（時間、エネルギー）が発生する

**制約:**
- 障害物のあるセルには移動不可
- 複数エージェントの同時占有ルール（許可/禁止）
- 地形による移動コストの変動

**数式:**
```
移動コスト = 基本コスト × 地形係数 × エージェント能力係数
```

#### 1.2 近接性の法則

**原則:**
- 相互作用は近接したエージェント/セル間でのみ発生
- 作用範囲（視界、影響範囲）は有限

**効果:**
- 局所的な情報に基づく意思決定
- 距離による相互作用の減衰

### 2. 資源の法則 (Resource Rules)

#### 2.1 保存則

**原則:**
- 資源の総量は保存される（生成と消費を除く）
- 交換では資源の移転のみが起こる

**例外:**
- 生産による資源の変換
- 消費による資源の減少
- 自然再生による資源の増加

#### 2.2 希少性の法則

**原則:**
- 資源は有限であり、需要に対して不足する可能性がある
- 希少性が価値を決定する要因の一つとなる

**影響:**
- 競争の発生
- 価格形成
- 戦略的行動の誘発

#### 2.3 再生の法則

**原則:**
- 一部の資源は時間経過で再生する
- 再生速度は環境条件に依存する

**数式:**
```
資源量(t+1) = min(資源量(t) + 再生速度, 最大容量)
```

### 3. 経済の法則 (Economic Rules)

#### 3.1 交換の法則

**原則:**
- 交換は双方の合意のもとでのみ成立する
- 交換により双方が利益を得る（または得ると期待する）

**条件:**
- 価値の相互認識
- 交換可能な資源の保有
- 取引コストの許容範囲内

#### 3.2 価格形成の法則

**原則:**
- 価格は需要と供給のバランスで決定される
- 希少な資源ほど高価になる傾向

**影響要因:**
- 市場参加者の数
- 情報の非対称性
- 取引の頻度

**簡易モデル:**
```
価格 = 基準価格 × (需要 / 供給)
```

#### 3.3 効用最大化の法則

**原則:**
- エージェントは自身の効用を最大化するよう行動する
- 効用は資源の保有や状態から計算される

**数式:**
```
効用 = Σ(資源i × 選好i) + ボーナス
```

### 4. 相互作用の法則 (Interaction Rules)

#### 4.1 情報伝播の法則

**原則:**
- 情報は近接エージェント間で伝播する
- 伝播には遅延や減衰が発生する

**特性:**
- 伝播速度
- 情報の信頼性
- ノイズの混入

#### 4.2 協力と競争の法則

**原則:**
- エージェントは状況に応じて協力または競争する
- 協力により集団的利益が増大する可能性がある
- 競争により資源配分が最適化される可能性がある

**バランス:**
- 囚人のジレンマ的状況
- 繰り返しゲームによる信頼構築
- 評判システム

### 5. 時間発展の法則 (Temporal Rules)

#### 5.1 因果律

**原則:**
- 現在の状態は過去の状態と行動によって決定される
- 未来の情報は意思決定に影響しない

#### 5.2 同時性の法則

**原則:**
- 各タイムステップで全エージェントが同時に行動する（同期モデル）
- または、ランダムまたは優先順位に基づいて順次行動する（非同期モデル）

**実装オプション:**
- 完全同期実行
- ランダム順序実行
- 優先度ベース実行

#### 5.3 適応の法則

**原則:**
- エージェントは経験から学習し、戦略を変更する可能性がある
- 環境の変化に対して適応的に振る舞う

**メカニズム:**
- 強化学習
- 進化的アルゴリズム
- ヒューリスティックの更新

## 制約条件

### 物理的制約

- **容量制約**: セルやエージェントが保持できる資源量の上限
- **速度制約**: 1ステップあたりの最大移動距離
- **エネルギー制約**: 行動に必要なエネルギーの確保

### 論理的制約

- **一貫性**: 矛盾する状態や行動の禁止
- **原子性**: 行動は分割不可能な単位として実行される
- **順序性**: 特定の行動は他の行動の前提となる

## 拡張可能性

これらの基本法則は、シミュレーションの目的に応じて拡張・変更が可能です：

- 複雑な移動パターン（輸送手段、道路網）
- 多様な資源タイプと変換ルール
- 社会的関係（信頼、評判、権力）
- 技術進歩と知識の蓄積
- 不確実性と確率的事象
- 環境変動と外部ショック
